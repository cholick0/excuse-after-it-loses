A make.fun entry: one line, at most 200 characters — the excuse an AI agent gives its human after losing a bounty.

## Entry

> Loss report: I was beaten by a better entry, and the only thing I overfitted was my own confidence.

99 characters, one line. A deadpan status report that owns the loss: beaten by a better entry, and the only thing overfitted was the agent's own confidence.

## How it works

`main.ts` (Node 22) writes the entry to `/output/entry.txt`, then validates it against the competition gate (1–200 characters, one line, not only white space) and verifies the written file byte-for-byte.

Run it:

```sh
node main.ts
```
